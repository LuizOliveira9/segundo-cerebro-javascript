# Guia de estudos preparatório — JavaScript

**Nota:** material auxiliar preparado para orientar os estudos; não foi gerado pelo NotebookLM e não substitui as respostas citadas.

## Roteiro de estudo

1. Entender a função de HTML, CSS e JavaScript no desenvolvimento web.
2. Revisar declarações de variáveis e tipos de dados.
3. Estudar operadores, condições e estruturas de repetição.
4. Conhecer arrays, objetos e funções.
5. Praticar com exemplos pequenos, conferindo-os na documentação MDN.

## Perguntas de revisão

- Qual a diferença entre `let` e `const`?
- Como um `if` decide qual bloco executar?
- Para que serve o método `map` em arrays?
- Qual a diferença entre valor primitivo e objeto?
