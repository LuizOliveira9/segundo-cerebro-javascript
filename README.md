# Segundo Cérebro com IA — JavaScript

Projeto desenvolvido para o desafio de criação de um notebook de estudos com IA da DIO.

## Tema e objetivo

**Tema:** Fundamentos de JavaScript para desenvolvimento web.

**Objetivo:** Construir um caderno de estudos assistido por IA para compreender JavaScript e revisar conceitos com respostas fundamentadas em fontes técnicas confiáveis.

## Fontes efetivamente adicionadas ao notebook

| Fonte | Formato | Por que foi selecionada |
|---|---|---|

## Diretriz de comportamento

Diretriz **preparada** para uso nas configurações do notebook (ainda não foi possível comprovar pela captura que esteja configurada):

> Atue como um tutor de JavaScript para estudantes iniciantes de Análise e Desenvolvimento de Sistemas. Responda em português brasileiro, explique conceitos com clareza, utilize as fontes importadas e apresente citações verificáveis. Quando não encontrar uma informação nas fontes, declare essa limitação em vez de inventar dados.

Arquivo: [DIRETRIZ_NOTEBOOK.txt](DIRETRIZ_NOTEBOOK.txt).

## Teste realizado

**Pergunta enviada:**

> O que são variáveis em JavaScript? Explique com exemplos e cite as fontes.

**O que o notebook respondeu (síntese da captura):**

O notebook apresentou variáveis como um dos recursos fundamentais da linguagem e identificou as declarações `var`, `let` e `const`. Também mencionou escopo, *hoisting* e modo estrito. Ele indicou que os trechos encontrados não forneciam exemplos práticos suficientes para atender integralmente ao pedido.

**Fontes citadas na resposta:** documentação MDN, em tópicos de declarações, gramática/tipos e modo estrito. Os marcadores numerados de citações aparecem na resposta. A abertura de cada trecho citado ainda precisa ser validada diretamente no notebook.

## O que aprendi

Fontes de formatos diferentes podem ser consultadas em um único notebook para apoiar a revisão de conteúdo. É importante conferir as citações e reconhecer quando uma resposta não está totalmente fundamentada nas fontes, como ocorreu na pergunta sobre variáveis.
