# Como finalizar a entrega

1. Acesse o repositório do GitHub e clique em **Add file → Upload files**.
2. Envie o PDF `JavaScript_Essencial.pdf` para a pasta `materiais/` e o print `notebook-fontes-citacoes-estudio.png` para `evidencias/`. Se necessário, crie as pastas pela interface usando **Create new file** com caminho `materiais/.gitkeep` ou `evidencias/.gitkeep`.
3. Abra o notebook e confirme a diretriz nas opções de configuração.
4. Exporte o mapa mental do Estúdio e envie o arquivo para `materiais/`.
5. Abra uma citação na resposta para verificar o trecho; faça um print adicional, se possível.
6. Confira se o link `https://notebooklm.link.google/aFbvENUch0vx` abre numa janela anônima.
7. Verifique os arquivos e marque os itens correspondentes no README.
8. Envie para a DIO o link **https://github.com/LuizOliveira9/segundo-cerebro-javascript** (não o link do notebook).
